# Book Catalog

Веб-приложение для каталогизации, поиска, управления и заказа книг.

## Основные возможности

- **Каталог и поиск:** Просмотр списка книг с фильтрацией по жанрам, поиском по названию/автору и пагинацией.
- **Корзина и заказы:** Управление товарами в корзине (добавление, изменение количества) и оформление заказов.
- **Избранное:** Добавление книг в список избранного.
- **Личный кабинет:** Регистрация, авторизация пользователей и редактирование профиля.
- **Администрирование:** Импорт книг и редактирование информации о книгах.

## Как установить и запустить

1. Клонируйте репозиторий или поместите проект в корневую папку вашего локального веб-сервера (например, OpenServer, XAMPP, Docker).
2. Настройте подключение к базе данных MySQL в файле конфигурации (`includes/db.php`).
3. Запустите локальный сервер (Apache/Nginx + PHP) и откройте проект в браузере.

## Используемые технологии

- **PHP**
- **MySQL** (через MySQLi)
- **JavaScript (jQuery, Fetch API)**
- **HTML5 / CSS3**
